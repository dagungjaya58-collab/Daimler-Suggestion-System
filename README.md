# DAIMLER - Sistem Saran & Masukan

## 📌 Tentang Sistem
Sistem ini adalah platform digital untuk menampung, mengelola, dan menindaklanjuti saran serta masukan dari seluruh karyawan. Tujuannya untuk meningkatkan kualitas kerja, keselamatan, efisiensi, dan inovasi di perusahaan.

## ✨ Fitur Utama
- 📝 Kirim saran secara mudah dan cepat
- 📊 Pantau status saran yang dikirim
- 🔄 Proses peninjauan dan umpan balik
- 🏆 Apresiasi untuk saran yang diterapkan

## 🚀 Cara Penggunaan
1. Buka halaman utama sistem
2. Isi formulir saran dengan jelas
3. Kirim dan simpan nomor referensi
4. Pantau status melalui halaman pelacakan
